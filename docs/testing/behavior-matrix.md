# Behavior-to-test matrix

Statement coverage is a regression floor. The named assertions below are the correctness argument; local component and E2E suites prove wiring and never replace focused tests.

| Critical behavior | Focused unit/contract evidence | Local component/E2E evidence |
| --- | --- | --- |
| Supplied OpenAPI text, named schemas, required fields, constraints, examples, descriptions, refs, responses, and extension boundary | `TestOpenAPIContractMatchesSuppliedArtifactExactly`, `TestOpenAPIContractIsStructurallyComplete`, `TestOpenAPIRequestAndResponseSchemasRetainEveryConstraint` | `make test-contract` runs both parsed and byte-equality gates. |
| Required-property presence, nullability, unspecified properties, and exact response shape | `TestIngestRejectsEveryMissingRequiredProperty`, `TestIngestNullabilityMatchesContract`, `TestIngestAcceptsUnspecifiedProperties`, `TestIngestResponseHasExactContractShape` | Every E2E sends a contract-valid object; default flows run unauthenticated unless the explicit auth extension is selected. |
| Runtime transaction types, Unicode bounds, currency, fixed-point amount, UTC, and identifier rules | `TestTransactionRequiresExplicitConfiguredType`, `TestLoadConfigAcceptsContractCurrencyAndRuntimeTransactionTypes`, `TestTransactionUsesOpenAPIUnicodeLengthBoundaries`, `TestTransactionAcceptsSchemaValidCurrencyValues`, `TestTransactionDecimalGrammar`, `TestTransactionRequiresUTCAndAllowsHistoricalFractionalTime`, `TestAcceptRejectsMissingIdentifier` | Smoke and all storage E2E paths submit validated toll transactions. |
| Lossless arbitrary objects and number-safe canonical fingerprints | `TestIngestUsesNumberSafeArbitraryObjects`, `TestIngestRetainsRawPassthroughBytes`, `TestFingerprintCanonicalizesRawObjectFormattingWithoutLosingNumbers`, `TestTransactionRejectsInvalidRawPassthroughShape` | NDJSON, PostgreSQL, DynamoDB, and Kafka component paths exercise the production mappings. |
| Raw bytes across adapters | `TestStoreCopiesRawAuditBytes`, `TestStorePersistsRawAuditBytesAcrossRestart`, PostgreSQL raw-column expectations, DynamoDB binary-attribute expectations | Real PostgreSQL and DynamoDB Local storage contracts plus NDJSON restart E2E. |
| New acceptance, stable replay, changed-content conflict, and one event | `TestAcceptNewAndReplay`, `TestAcceptReplayReturnsPersistedTransactionID`, adapter replay/conflict tests | All implementations assert `201`, identical `200`, changed duplicate `400`, and one event; the default smoke repeats replay after restart. |
| Atomic transaction plus pending outbox | `TestStoreAcceptsTransactionAndOutboxInOneSQLTransaction`, `TestStoreAcceptsWithConditionalTransactionalWrite`, `TestStoreRollsBackWhenOutboxInsertFails` | Shared real-store component contract and separate-process PostgreSQL/DynamoDB E2E. |
| Concurrent acceptance, lease exclusion, expiry, fencing, retry, and terminal outcome | `TestStoreSerializesConcurrentDuplicates`, `TestStoreRejectsCompletionFromExpiredClaimOwner`, `TestDispatcherRetriesAndTerminatesFailedEvents`, adapter lease tests | Shared PostgreSQL and DynamoDB contracts race acceptance/claims and reject stale completion. |
| Kafka stable key, versioned envelope, number safety, at-least-once failure visibility | `TestPublisherWritesNewPayload`, `TestPublisherEmitsNumberSafePassthroughFromRawAuditFields`, `TestPublisherPropagatesWriterFailure` | Plaintext and TLS/SCRAM Kafka components consume the versioned event and exercise failure paths. |
| Optional API-key extension and secret safety | `TestStaticAPIKeysAuthenticatesConfiguredKeys`, `TestStaticAPIKeysRejectsEmptyAndUnknownKeys`, `TestIngestAuthAndResultBranches` | Auth is disabled for the supplied default contract; secret-provider and secure-Kafka E2E paths explicitly enable and verify authentication. |
| Media type, body size, malformed input, safe errors, and resource limits | `TestIngestRejectsMediaAndMalformedJSON`, `TestIngestRejectsOversizedBody`, `TestIngestRejectsInvalidTimestampAndTrailingJSON`, `TestNewHTTPServerHasExplicitResourceLimits` | Smoke and E2E dependency-failure paths exercise production process boundaries. |
| Health, store-backed readiness, metrics, and method guards | `TestOperationalEndpointsAndGuards`, runtime readiness tests, adapter readiness tests | Compose waits for health; every storage-backed E2E uses the documented readiness endpoint. |
| Storage migration/backward shapes and dependency failures | `TestMigrateAppliesEmbeddedSchemaAndWrapsFailure`, `TestSchemaDefinesAtomicIdentityAndOutboxLeaseState`, malformed/missing-attribute adapter tests | Real local PostgreSQL and DynamoDB components validate migrations/tables without cloud credentials. |
| Infrastructure and security policy | HTTP/Kafka/secret/config unit suites, container/CI/infrastructure contracts | `make test-infrastructure` and `make security` validate without apply or production credentials. |
| Cleanup and isolation | Shell contract assertions require scoped traps and teardown | Smoke, component, and E2E scripts remove their repository-scoped containers, volumes, networks, temporary credentials, and files. |

Fixtures keep valid and invalid paths explicit. Helpers do not coerce invalid inputs into valid contract values, and arbitrary JSON cases use exact numeric lexemes rather than floats.
