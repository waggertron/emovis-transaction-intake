# Engineering Stack Requirements

## Core Responsibilities

- Design and develop scalable, high-performance back-end services and APIs in Go, and build modern front-end applications (React, Vue, or Angular) to deliver seamless end-to-end user experiences.
- Architect and deploy cloud-native solutions on AWS (ECS/EKS, Lambda, RDS, DynamoDB, SQS/SNS, CloudFront), including containerized workloads and orchestration via Docker and Kubernetes.
- Design, build, and maintain CI/CD pipelines and Infrastructure as Code (Terraform, Ansible, or CloudFormation) to ensure reproducible, auditable, and continuously delivered environments.
- Integrate Claude AI APIs and tooling into product features and internal developer workflows, building agentic and multi-step AI workflows that automate complex back-office processes.
- Design and implement prompt engineering strategies (system prompts, few-shot examples, chain-of-thought patterns, tool use) and evaluate AI models and approaches, balancing capability, latency, cost, and compliance.
- Implement responsible AI practices—including output validation, hallucination mitigation, PII handling, and audit logging—for all AI-assisted features.
- Write clean, well-tested, and well-documented code, championing test-driven development (TDD) and code review practices across the team.
- Monitor system and application health using observability tools (for example, Datadog, Prometheus, Grafana, and the ELK stack), respond to incidents with urgency, and drive automation to reduce manual toil.
- Embed security and compliance throughout the development and DevOps lifecycle, including secrets management, access controls, and vulnerability scanning, while supporting capacity planning and cloud cost optimization.
- Participate in system design discussions and drive API design and integration patterns between internal microservices and third-party tolling or government systems.
- Mentor mid-level and junior engineers, and stay current with emerging technologies—particularly in the AI/LLM and platform engineering space—evaluating their applicability to Emovis' platform roadmap.

## Experience Requirements

- Ability to thrive in an environment of ambiguity, shifting priorities, and complex organizational structures.
- 6+ years of professional software engineering experience, with at least 3 years in a senior or lead capacity spanning both development and DevOps/platform responsibilities.
- Strong proficiency in Go (Golang) for building production-grade microservices and REST/gRPC APIs.
- Demonstrated full-stack capabilities: back-end services in Go and front-end development in Angular, React, Vue, or comparable modern frameworks.
- Specific hands-on experience with Angular is required. This is a true full-stack role, and candidates should be comfortable owning both front-end (Angular) and back-end (Go) code in production.
- Deep hands-on experience with AWS, including compute (EC2, ECS, Lambda), storage (S3, RDS, DynamoDB), networking (VPC, ALB, Route 53), and serverless patterns.
- Proven DevOps experience with CI/CD tooling such as GitHub Actions, GitLab CI, Jenkins, or Azure DevOps.
- Proficiency in Infrastructure as Code (Terraform, Ansible, or CloudFormation) for managing reproducible, auditable environments.
- Practical, hands-on experience developing with LLM APIs, with strong preference for Claude (Anthropic)—including API integration, prompt engineering, tool use/function calling, and streaming responses.
- Demonstrated ability to design and ship AI-powered features in production: agentic workflows, document processing, intelligent search, or conversational interfaces.
- Solid understanding of prompt engineering techniques: system prompt design, few-shot prompting, chain-of-thought reasoning, retrieval-augmented generation (RAG), and structured output patterns.
- Experience with AI safety and responsible deployment practices, including output validation, content filtering, PII redaction, and audit logging.
- Familiarity with AI/ML-adjacent tooling such as LangChain, LlamaIndex, vector databases (for example, Pinecone and pgvector), or embedding pipelines is a plus.
- Solid understanding of containerization (Docker) and orchestration (Kubernetes/EKS).
- Experience with secrets management tools such as HashiCorp Vault or AWS Secrets Manager.
- Proficiency with SQL and NoSQL databases; ability to design schemas and optimize queries at scale.
- Familiarity with observability tooling (Datadog, Prometheus/Grafana, ELK/OpenSearch) and a culture of SLO-driven engineering.
- Strong understanding of networking fundamentals, security practices, and cloud cost management.
- Strong communication and stakeholder-management skills; able to translate complex technical trade-offs to non-technical audiences.
- Experience in the tolling or transportation industry is highly preferred.
